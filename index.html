Triển Khai Firebase (CSDL Thời Gian Thực) & Xuất Định Kỳ Google Sheets (6 Sheets)

Đã kết nối Gateway

Lưu trữ tức thì trên Firebase Realtime Database & tự động xuất định kỳ toàn bộ 6 Sheet về Google Sheets qua Cloudflare Worker

0. Cổng Xác Thực Trung Gian — Cloudflare Worker Auth Gateway (Khuyên Dùng Cho GitHub Pages)

Toàn bộ FIREBASE_DB_URL, FIREBASE_WEB_API_KEY, GAS_WEB_APP_URL và SECRET_TOKEN được ẩn hoàn toàn trong biến môi trường Cloudflare Worker & Firebase. Khi bấm Xuất HTML GitHub (Zero-Secret), chỉ duy nhất địa chỉ Cloudflare Worker Auth Gateway URL này được dán sẵn vào mã HTML!

Qua Worker Gateway
1. Ứng Dụng Web → 2. Cloudflare Worker + Firebase (Ẩn Bí Mật) → 3. Google Sheets (6 Sheet Định Kỳ)
Tự động (5p)

B. Xuất / Đồng Bộ Định Kỳ Về Google Sheets (Đầy Đủ 6 Sheets)

Đồng bộ qua Cloudflare Gateway: Firebase là nguồn dữ liệu chính, Worker chuyển tiếp sang Google Sheets. Toàn bộ mã URL Google Sheet và các mã bảo mật đã được ẩn hoàn toàn trên giao diện trình duyệt.

Tự động đẩy sang Google Sheets khi cập nhật Firebase & theo định kỳ Giúp bảng tính Google Sheets luôn có số liệu mới nhất để lưu trữ và báo cáo
Chu kỳ tự động đồng bộ Tự động làm mới dữ liệu giữa các máy

Mã Nguồn Cloudflare Worker (worker.js) — Ẩn URL Google Sheet & Mã Bảo Mật

Giấu 100% FIREBASE_DB_URL, FIREBASE_DB_SECRET, GAS_WEBAPP_URL và GAS_SECRET_TOKEN trong biến môi trường của Worker. Kiểm soát Single Active Session và phân quyền admin (toàn quyền) / user (chỉ bổ sung thông tin).

Mã Nguồn Google Apps Script (Code.gs) — Đồng Bộ 6 Sheet & Xác Thực GAS_SECRET_TOKEN

Tự động khởi tạo và đồng bộ 6 sheet (DM_Chung, KeHoach_Nam, NhatKy_SuKien, DM_ND22, DM_TT20, TaiKhoan). Bắt buộc: Vào Project Settings (Cài đặt dự án) → Script properties (Thuộc tính tập lệnh) thêm thuộc tính GAS_SECRET_TOKEN trùng khớp với biến GAS_SECRET_TOKEN trên Cloudflare Worker.

Firebase Realtime Database Security Rules (database.rules.json)

Bảo vệ phân quyền admin (toàn quyền) và user (chỉ thêm mới hoặc điền bổ sung trường còn trống, cấm ghi đè/xóa dữ liệu cũ).

🚀 Quy Trình Triển Khai Chuẩn Zero-Secret (Cloudflare Worker + Firebase + Google Sheet)

  1. Bước 1 (Google Sheet & Script Properties): Mở file Google Spreadsheet, vào Tiện ích mở rộng → Apps Script, dán mã ở Tab 3 (Code.gs). Tiếp theo, vào mục ⚙️ Project Settings (Cài đặt dự án) → Script properties (Thuộc tính tập lệnh) → Add script property, khai báo khóa GAS_SECRET_TOKEN với giá trị mã bí mật của bạn, sau đó bấm Triển khai → Ứng dụng web (Anyone).
  2. Bước 2 (Firebase Realtime Database): Tạo project Firebase, bật Realtime Database, dán cấu hình Tab 4 (database.rules.json) vào tab Rules.
  3. Bước 3 (Cloudflare Worker — Ẩn toàn bộ URL Google Sheet & Mã bảo mật): Tạo Worker trên Cloudflare, dán mã ở Tab 2 (worker.js). Trong phần Settings → Variables and Secrets của Worker, lưu kín các biến môi trường: FIREBASE_DB_URL, FIREBASE_DB_SECRET, GAS_WEB_APP_URL (hoặc GAS_WEBAPP_URL), và GAS_SECRET_TOKEN (phải trùng khớp 100% với GAS_SECRET_TOKEN trong Script properties của Google Apps Script).
  4. Bước 4 (Xuất HTML GitHub Zero-Secret): Dán Cloudflare Worker Auth Gateway URL vào Tab 1 rồi nhấn nút 🛡️ Xuất HTML GitHub (Zero-Secret). Hệ thống sẽ tự động dán địa chỉ Cloudflare Worker Auth Gateway URL vào mã HTML và xóa sạch mọi dữ liệu/mã bảo mật để bạn tải lên GitHub Pages an toàn tuyệt đối.
